# 数据飞轮标注成果说明

本目录是数据飞轮产出的标注数据包，供后续训练、人工复核与团队汇总使用。它不等同于整套参赛作品或正式推理程序。实际样本数量、数据版本、来源、未完成项和内容哈希以 `manifest.json` 为准。

## 标注文件与读取

`annotations/<视频>/<标注群组>/confirmed.coco.json` 保存人工标注或有人工确认状态的可见实例；`candidates.coco.json` 保存机器候选及未确认插值。同一文件的图像 ID、实例 ID 为正整数，类别 ID 为 1，类别名称为 bee。它们是 COCO 索引，不是蜜蜂轨迹 ID。原始身份保存在 `source_track_id`，作用域见 `audit/records.jsonl`，跨视频、标注群组或独立区段不能直接合并。

COCO 的 `file_name` 是相对于图像根目录的可移植引用。标注包不含图像或视频。读取完整质量信息时，应同时读取审计记录；普通 COCO 读取器不会自动使用伪标签权重或忽略区域。

人工确认只说明相应实例的确认状态，不等于整张图像已经穷尽标注。只有明确标有 `annotation_complete=true` 的帧才声明完整。未经确认的空帧不导出成可靠负样本。候选文件不得直接作为验证/测试真值使用。

## 坐标与关键点

原点为原图左上角，x 向右、y 向下，单位为像素。源框为 xyxy，COCO 框为 `[left,top,width,height]`，宽高严格大于零，不添加像素长度的 `+1`。框边界允许位于图像宽、高的边界线上；越界部分裁剪到图像范围，原框与裁剪动作均记录在审计文件中，退化框仅留审计。

标注对象按可见全躯干及正常展开翅膀的最小外接矩形解释；边缘截断或遮挡个体保留其可辨认的可见部分。格式转换无法证明已有框已满足该生物学边界，边界质量仍需复核。

保留本项目已有两个关键点：`head`、`abdomen_tip`，可视化连接为 `[1,2]`。COCO 关键点采用 `[x,y,v]`：v=0 不存在，坐标为 0；v=1 已明确标注为遮挡；v=2 存在。源模型第三列是置信度，保留在审计中，不把它直接当作可见性。没有显式遮挡标签时，不凭低置信度制造“被遮挡”标签。图像外的点记作缺失并记录转换原因。正式 POSE 推理的点数建议和 OKS sigma 不是本数据包的要求。

## 划分与抽帧

`splits/train.txt`、`val.txt`、`calibration.txt`、`test.txt`、`unassigned.txt` 使用相对图像引用。空文件表示没有相应已声明样本。源划分原样保留；不把 calibration 改名为 val，不把未划分候选加入训练，更不会为凑齐 train/val 随机拆开相邻帧。这里的 test 是团队自有留出集，不是赛事隐藏测试集。

导出会拒绝同一物理源帧出现在不同的已分配划分中。轨迹跨集合、相邻区段和近重复的隔离仍须由训练实验的分组划分契约验证；本导出校验不能代替该验证。

`frame_manifest.jsonl` 保留源帧编号，绝不套用正式推理文件的 1-based 编号。源编号基准未知时明确为 null，不能凭经验补全。确认编号基准后，可在 Linux 等开发环境运行：

```bash
python extract_frames.py --video /path/A-5-1.mp4 --video-id A-5-1 \
  --frame-manifest frame_manifest.jsonl --index-base 0 --output /path/reproduced_frames
```

脚本需要 OpenCV，顺序解码并按清单抽帧。`--index-base` 必须与源帧约定相符。该操作复现源帧选择与尺寸；若原始编码参数不同，不承诺 JPEG 文件字节完全一致。

## 质量复核与异常处理

重叠本身不证明重复个体。20% IoMin 规则只处理已有方案中的冲突插值可见性；独立观测框不会在格式转换时被 NMS 或数量上限删除。当前阈值、轨迹来源及此前处理版本由源记录和源版本说明。

`audit/records.jsonl` 保留隐藏插值、人工拒绝、忽略区、几何修复和实例来源。隐藏不是删除身份；忽略区不是标准 COCO 的 crowd，不能将二者混为一谈。训练时采用本项目质量/监督字段，或显式实现忽略区域屏蔽。

多人数据按标注群组分别保存。同帧多人标注未仲裁前不可直接叠加为多只蜜蜂。人工复核应记录操作者、动作、修改前后结果；有记录的决定才可计为已完成复核。此包不会声称尚未执行的交叉复核已经完成。

输入配置可用 `review_audits` 提供已有复核日志路径；日志原样保存到 `audit/reviews/` 并记入哈希清单。没有提供日志时，只保留源标签的确认状态，不声称完成独立复核审计。

## 来源与版本

`manifest.json` 和 `resolved_config.json` 记录源文件哈希、数据版本、外部数据声明及待确认项。新版本使用新目录，不能覆盖旧版。外部公开数据参与增强、预训练或提示时，需列明来源、用途、许可和是否进入当前快照；声明不完整必须保留为待补项。

质量校准、复核命中率、错误回流和划分完整性用于审视飞轮本身；mAP、MOTA、IDF1 等用于固定协议下的下游价值验证。没有下游完整实验时，不据此否定已完成的数据工程，也不声称飞轮已带来精度收益。
