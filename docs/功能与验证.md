# 功能实现与验证状态

这份清单对应原方案功能，不把“能导入模块”算成模型效果验证。`机制测试`验证数学或数据契约，`模型运行`验证真实网络执行，`历史结果`沿用已有实验；完整收益需固定划分消融。

## 当前方法范围

正文保留已有代码实现的室内外标注、共享双域模型、六阶段联合训练、Q²/Q-MoE、采样增强、主动复核和知识更新。方法机制与实际实验结果分别记述；外部环境条件未提供，相应解释退出当前报告与默认入口。

本轮修正 `behavior.analyze`：插值和已拒绝实例不参与数量、运动与关系统计，保留源标注。32 个真实源帧的观测汇总从 8,319 改为 6,587，标注内容逐项相同。新增 `interpret_colony` 的视频变化复核默认模式，并在 A-5-1 的 5,400 帧上生成真实候选。证据见 [video_only_revision.json](../evidence/video_only_revision.json)。

## 本次文档与代码连接修复

学术正文为 `Hive_Q2K_Dual_方法.md`；同名室内配图版同步正文。正式标注说明为 `src/label_data_flywheel/assets/数据标注说明-595335.docx`，内部 COCO 交换说明独立标明用途。

| 对应文档规则 | 可执行连接及回归 |
|---|---|
| 影子仅有检测类别 | LabelMe 同组的蜂体与影子分开导入；影子不进入姿态、ID、蜂体 COCO 或行为统计，原字段另留来源 |
| 灯光、模糊与堆叠区域覆盖不完全 | `annotation_complete=false` 保留人工正例，未知区域背景梯度为零；明确拒绝的局部框才提供负例；普通分类及硬负例损失均应用该规则 |
| 先修关联、后补框、再限制可见性 | `review.py → pipeline.py → postprocess.py`，复核后清理受影响旧插值，再按新 ID 重建；20% IoMin 和 16 像素阈值保留 |
| 漏标、姿态颠倒与 ID 切换进入误差归因 | 人工参考与一致性证据进入分层质量；头尾原配/交换和轨迹投票均接入轮次；测试参考不能改变训练质量 |
| 误差改变学习机会及监督强度 | ErrorCube 分域/视频/尺度/密度/交叠/朝向/质量切片进入目标分布，Q² 直接写入训练损失权重 |
| 复核意见实际回流 | LabelMe 任务导出、修改导入、标签更新、提示记忆、知识支持度和下一轮策略已连接；群体时间窗不广播为个体标签 |

| 正式提交目录精简 | 检测/姿态/MOT 三个平行目录，train/val 占位、抽帧脚本与最新版 Word；审计、元信息和额外划分放同级附加目录 |

## 当前默认执行路线

使用已有标注或选定模型生成实体，进行跨层一致性分析与复核排序；群体入口采用 `interpret_colony(report)` 的纯视频模式。`interpret_external_context` 保留为将来接入外部记录的独立函数，默认流程不调用。

当前群体复核没有实际人工行为标签，训练桥接的 348 个真实框只用于验证数据加载，E 网络验证为随机初始化的前反向执行。它们不构成完整再训练结果，详见 `e_gpu.json`、`training_bridge.json` 与 `model_registry.json`。
