# 可观测性约束的蜂群时空表征与生产事件证据链

本部分对应用户要求补齐的 2.2、2.3：将逐帧标注转化为群体状态、时序变化和带文献来源的蜂学复核线索，再进入数据飞轮。实现入口为 `bee-flywheel colony`；不更改既有最优室内后处理、室外原版 SAM、原框和历史标注。

## 2. 可观测性分层的群体测量

以域、视频和标注组构成身份作用域 $s=(d,v,g)$。对时间窗 $W_k$，区分实际观测集合 $O_f$、可见插值集合 $I_f$ 和审计隐藏集合 $H_f$。行为计算默认只使用 $O_f$；另列 $|I_f|$ 和 $|H_f|$，避免把补框数量当作真实活动证据。

曝光时间为 $T_k=|F_k|/r$，其中 $r$ 是源帧率；覆盖率为 $T_k/((f_{last}-f_{first}+1)/r)$。未读取的帧不伪装成零活动。对没有持续轨迹的对象，运动状态为不可测；活动比例只在有效运动测量中计算，同时显示其覆盖比例。

### 2.1 有限线段上的巢口通量

设置归一化端点 $a,b$ 和内部侧符号。框中心到有向线的符号距离为

$$d(c)=\frac{(b_x-a_x)(c_y-a_y)-(b_y-a_y)(c_x-a_x)}{\|b-a\|}.$$

使用死区、连续侧向确认、有限线段交点检查和短时冷却，拒绝缺帧跨接或速度异常跳变。当前默认死区 5 像素、确认 0.1 秒、最大观测缺口 0.15 秒；需要按具体巢口标定。确认后的通量为

$$J_{in,k}=60N_{in,k}/T_k,\quad J_{out,k}=60N_{out,k}/T_k,\quad J_{net,k}=J_{in,k}-J_{out,k}.$$

只有 `calibration_status=verified` 且覆盖率达到阈值时才输出 `entrance_flux_per_minute`。未核验的线只产生 `reference_line_only`，未配置则返回空值。进出差不是死亡数，穿越次数也不是跨完整采集行程配对后的归巢率。

### 2.2 计数守恒的空间密度

把原图框中心映射到 64×36 归一化网格，每个核在图像边界重新归一化：

$$D_k(u)=\frac1{|F_k|}\sum_{f\in F_k}\sum_{i\in O_f}\frac{K_\sigma(u-c_{if})}{\sum_{z\in\Omega}K_\sigma(z-c_{if})}.$$

因此 $\sum_uD_k(u)=\operatorname{mean}_{f\in F_k}|O_f|$。热图表示每格平均观测目标数，不是分割掩膜、物理面积密度或经召回校准的真实总蜂数。不同时间窗采用同一色标；默认展示首窗、中间窗和末窗，不挑最有利的局部画面。

### 2.3 持续近邻与时间网络

使用 KD-tree 查找候选近邻；中心距离小于双方身体长度代理均值的 1.5 倍，并持续至少 0.3 秒后，开始累计合格近邻曝光时长。达到阈值之前的启动时间不追溯补计。该时长构成边权，输出加权度、连通分量、最大分量占比及边密度。

节点是时间窗内出现过的轨迹 ID，**不是某一帧同时存在的蜂数**。ID 碎片会增大累计节点数、改变网络统计，因此保留累计 ID、新增 ID 和运动可测比例供审计。已有定向交互/跟随候选仍保留；本次也修正了原群体加权图按标注组隔离的问题，避免同视频同帧的不同标注组混合。

### 2.4 前向基线下的时序偏离

输出计数、活动比例、身体长度代理速度和密度异质性的趋势；当前窗只使用前 6 个连续历史窗建立中位数/MAD 基线，不使用未来数据校准当前异常。稳健偏离为

$$z_k=\frac{x_k-\operatorname{median}(x_{k-6:k-1})}{\max(1.4826\operatorname{MAD},0.05|\operatorname{median}|,0.01)}.$$

默认 $|z_k|\ge4$ 产生复核候选。至少 12 个完整等间隔时间窗才做去趋势自相关；周期候选要求局部峰值、自相关超过 0.5 且至少可观察三个周期。即使有峰，也不将几分钟片段解释成昼夜节律。默认运动量使用 0.3 秒位移，而不是单帧框抖动；姿态不足时采用框长边代理，图中明确单位为“身体长度代理/秒”。

## 3. 蜂学意义与生产复核

蜂学解释采用三层证据链：可观测变化 → 与之同时发生的外部证据 → 具名人工复核。默认没有外部上下文，系统不会虚构天气、温度或事件真值。

| 应用场景 | 触发联合复核需要什么 | 输出的实际用途 |
|---|---|---|
| 天气与热环境 | 视觉变化 + 有来源的温度基线/风雨记录 | 核对同时间段环境、摄像机变化和蜜粉源；优先现场检查水源、遮阳、通风条件 |
| 分蜂相关线索 | 视觉变化 + 已核验王台、振动候选或同期重量变化中的相关证据 | 确定需要调阅长时记录、检查王台和蜂群状态的片段，不直接宣布即将分蜂 |
| 疑似农药暴露 | 视觉变化 + 真实施药记录 + 死蜂记录 | 保留视频、暴露时间和样本，供专业人员进一步排查；不推断药剂、剂量或中毒诊断 |

外部记录须提供 `domain/video/group/window_index/source/measurements`，作用域不匹配或无来源的记录不参与推断。允许温度、基线温度、风速、雨量、重量变化、王台核验、振动候选、施药和死蜂数；没有值的字段保持缺失。规则只产生 `review_candidate`、`insufficient_evidence` 或“本窗无联合信号”，`diagnosis` 始终为空；后者也不能解释为排除风险。

群体异常保存代表源帧范围，进入 `review_queue.json`。完整飞轮可通过 `colony.enabled=true` 启用本模块，并在既定复核预算中预留最多四分之一给群体候选。人工先复查漏检、重复、遮挡和身份跳变，再判读行为；未经确认的候选不自动成为行为训练 GT。

`bee-flywheel review-colony --input colony.json --decisions decisions.json --reviewer 实际复核人 --output 新目录` 支持具名确认、更正和拒绝。决定须带唯一 `decision_id`、候选 `event_id`、`action` 与实际人工标签 `human_label`；重复同一决定不重复累计，冲突的同名决定会报错。输出独立的 `confirmed_group_windows.json` 和前后审计。完整轮次可通过 `colony.review_decisions`/`reviewer` 将确认后的群体标签绑定到源时间窗；不会把群体判读广播为每一只蜜蜂的个体行为标签。

## 4. 真实运行与可复现入口

```bash
python -m pip install -e '.[vision,colony,test]'
bee-flywheel colony --config configs/colony.example.json --output /data/bee26/colony_round_001
```

输出 `colony.json`、输入哈希、解析配置、复核队列、中文总览图、统一色标密度对照和可离线打开的 `index.html`。运行拒绝覆盖已有输出；图像底图和逐对象私有结果留在服务器/用户主机，代码仓库只保留统计摘要及实现。

2026-09-08 实测选取 B-5-3、A-5-1 各源帧 1800–7199（60–240 秒、30 FPS），各 5,400 帧、18 个十秒窗。室内直接读取已选 appearance20 全量 ID 标注；室外全量姿态源不含 ID，因此仅在分析副本中调用已有备选关联器补身份，明确不替换原版 SAM 发布数据。

3090 核心测试共 49 项通过，包括群体事件确认后的时间窗回流与个体标签隔离。4090 两次实际分析的统计逐字段一致；第二次室内分析含绘图约 184 秒、室外约 49 秒。计数守恒、输入来源、执行模块和展示产物哈希见 [实际运行证据](../evidence/colony_180s.json)。最终展示复用同一份已验证群体统计，单独记录知识解释/绘图模块的版本来源。

| 实测量 | B-5-3 室内 | A-5-1 室外 |
|---|---:|---:|
| 每帧平均实际观测数 | 414.28 | 17.18 |
| 十秒窗平均观测数范围 | 393.98–440.62 | 13.46–22.63 |
| 片段累计不同轨迹 ID | 5,596 | 7,597（分析用备选关联） |

| 实际巢口通量 | 未配置 | 未核验，保持空值 |

室外待复核窗平均 22.63 个观测，前六窗基线中位数 17.25，稳健偏离约 6.24；这表示检测计数变化，不是已确认的蜂群异常。室外参考线共得到 12 次穿越，但短轨迹较多、巢口未标定，不能将该数称作真实出入蜂数。室内未触发当前配置的异常也不等于健康诊断。

当前实测支持统计、绘图、证据门控和复核入口可运行；不提供蜂学诊断准确率或生产预警提前量。后续效果评估需要跨日期、跨蜂箱的真实事件真值，以分蜂/暴露事件为单位划分训练与测试，报告召回、误报、提前量和人工复核成本；不能把同一事件的邻近帧随机拆分后宣称泛化能力。
