# 群体视频观测与蜂学研究

本页描述群体视频分析模块；完整联合训练、专家校准与知识反馈见[方法正文](Hive_Q2K_Dual_方法.md)。群体分析使用已有视频、检测、头尾姿态和轨迹。蜂体结构、身体尺度和持续近邻提供观测依据；默认报告生成数量、空间、运动变化对应的复核区段。

## 观测依据与方法

蜂群无标记追踪将个体位置、方向和身份连接起来（Bozek，Nature Communications 2021）。姿态动态研究说明测量噪声会改变行为判断（Keypoint-MoSeq，Nature Methods 2024）。蜂群通信研究表明身体朝向和间距具有生物学意义（Nguyen，PNAS 2021）。这些研究用于确定观察对象，原文链接和完整引用见 [方法正文](Hive_Q2K_Dual_方法.md)与[参考文献](references.bib)。

数量和密度只使用直接观测。空间核在视野内归一化，使密度积分等于直接观测数量；默认 64×36 网格、1.2 格核尺度、10 秒窗口。运动以 0.3 秒历史跨度计算，按可靠头尾长度或框长边归一化，记录运动可测覆盖。持续近邻要求距离不超过平均身体尺度的 1.5 倍，持续 0.3 秒后累计关系时长。

数量、活动比例、中位速度与密度变异系数分别使用前六个窗口的中位数和 MAD 构建基线，绝对偏离达到 4 时产生复核候选。源帧覆盖需达到 90%；数量与密度不要求持续 ID，运动判断还要求至少 50% 的观测具有可测运动。输出包含视频、源帧范围、当前值、基线值、偏离程度与复核方向。

## 实际结果

本轮在 3090 上直接使用 A-5-1 既有室外检测与姿态标注的源帧 1800—7199，共 5,400 帧、18 个窗口。平均直接观测数为 17.2072；源帧 6900—7199 平均观测数 22.6533，相对前六窗基线 17.2833，偏离 6.2141，形成 1 个数量上升复核候选。输入没有持续 ID，因此运动量保持未测，数量与密度正常生成。详见 [本轮真实验证](../evidence/video_only_revision.json)。

历史 B-5-3 的 20% 补框路线同区段统计仍保留：平均直接观测 414.2807、平均可见插值 103.7419、运动覆盖 78.8%—82.7%。其来源是 `full_20pct_20260907`，不是本轮重新运行的 appearance20；历史室外统计使用分析用备选关联，见 [历史证据](../evidence/colony_180s.json)。本轮室外使用不同位置的既有姿态标注，来源哈希与历史输入不同，两个统计摘要分别保存。

## 使用

```bash
bee-flywheel colony --config configs/colony.example.json --output /data/bee26/colony_round_001
```

输出 `colony.json`、`review_queue.json`、数量与密度图以及可离线打开的 `index.html`。完整轮次可通过 `colony.enabled=true` 接入群体候选。当前没有实际人工群体复核结果，候选不作为行为真值。

环境条件、分蜂、农药和热应激解释已从默认流程和方法正文移除。真实巢口未标定，默认图不显示参考线通量。独立扩展函数与历史记录留存，以便以后具备实际条件时再接入。
